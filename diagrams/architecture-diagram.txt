## Security Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                      DEFENSE IN DEPTH                           │
└─────────────────────────────────────────────────────────────────┘

Layer 1: Network ACL (Subnet Level)
┌─────────────────────────────────────────────────────────────────┐
│  • Stateless firewall                                           │
│  • Default: Allow all (can be restricted)                       │
└─────────────────────────────────────────────────────────────────┘

Layer 2: Security Group (Instance Level)
┌─────────────────────────────────────────────────────────────────┐
│  • Stateful firewall                                            │
│  • Inbound: HTTP (80) from 0.0.0.0/0                            │
│  • Outbound: HTTP (80), HTTPS (443)                             │
└─────────────────────────────────────────────────────────────────┘

Layer 3: IAM Role (Application Level)
┌─────────────────────────────────────────────────────────────────┐
│  • Least privilege access                                       │
│  • SSM Parameter Store read-only                                │
│  • No hardcoded credentials                                     │
└─────────────────────────────────────────────────────────────────┘

Layer 4: Application (Code Level)
┌─────────────────────────────────────────────────────────────────┐
│  • Input validation                                             │
│  • Error handling                                               │
│  • Secure coding practices                                      │
└─────────────────────────────────────────────────────────────────┘
```

This is a text-based representation of the architecture. For a visual diagram:

To create a professional diagram:
1. Import AWS architecture icons
2. Arrange components as shown in the text diagram
3. Add arrows to show data flow
4. Use colors to distinguish layers (network, compute, security)
5. Export as PNG and save to diagrams/architecture-diagram.png
